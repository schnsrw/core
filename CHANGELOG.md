All notable changes to **Casual Core** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added
- Initial public release of Casual Core, the document engine for Casual Office.
- Rust crates for the document model, operations, format readers/writers, layout, and text shaping.
- WebAssembly bindings (`@schnsrw/core`) for browser and Node consumers.
- C FFI bindings (`s1engine-c`) for native consumers.
- GitHub Pages demo at the project's Pages site.
