# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful. Disagree on the substance, not the person.
- Assume good faith.
- Harassment of any kind is not tolerated.
- Maintainers may remove, edit, or reject comments, commits, code, issues,
  and PRs that don't follow this Code of Conduct.

To report a problem, email **schnsrw@gmail.com**. Reports are confidential.
